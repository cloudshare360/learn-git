Replace all placeholder identity, links, and case-study content before publishing. Keep the page semantic, keyboard accessible, responsive, and useful without JavaScript.

## Local preview

From this folder, run a local static server or use the course server from the repository root. Do not place secrets in HTML, CSS, or browser JavaScript.

## Suggested Git workflow

1. Create an issue with acceptance criteria.
2. Update the pull request target branch.
3. Create a feature branch.
4. Commit focused changes after reviewing staged diffs.
5. Push and open a pull request.
6. Pass checks, review, merge, deploy, and verify.
