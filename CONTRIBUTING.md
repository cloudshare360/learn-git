# Contributing

Use an issue to define the learner problem and acceptance criteria. Create a focused feature branch from current `main`, preserve the lesson/content contracts, run `npm test`, and open a pull request with what changed, why, learner impact, and validation evidence.

For curriculum changes, identify the supported operating system and shell, explain every command, provide expected state and recovery, and include a useful visual text alternative. Do not add real credentials, private information, destructive shortcuts, or unlicensed assets.

See the [development guide](docs/04_development/01_development_guide.md) and [agent execution design](docs/02_planning/03_agent_execution_design.md).
