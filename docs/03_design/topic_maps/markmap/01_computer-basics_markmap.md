# 1. Files, folders & terminals

## Module overview

- Goal: Learn where work lives and how to move around safely.
- Lesson count: 4
- Visual types: tree, orientation, path, flow

## Lessons

### Files, folders, and paths

- Outcome: Create a three-level practice workspace and explain each part of its path.
- Terms:
  - directory
  - extension
  - path
- Key actions:
  - Open your file manager
  - Create the workspace
  - Create a text file
  - Read the location
- Command goals:
  - Create the folder tree in a terminal
- Visual: tree — Your first folder tree
- Practice: Create a sibling folder named images next to notes, rename it assets, then undo or rename it back to images.

### Navigate with Explorer, Finder, or Files

- Outcome: Move into, out of, and between folders using graphical controls.
- Prerequisites:
  - files-folders
- Terms:
  - path
- Key actions:
  - Enter a folder
  - Move to the parent
  - Use Back and Forward
  - Copy and move safely
- Visual: orientation — File manager landmarks
- Practice: Navigate Documents > learn-git > practice > images, then return to learn-git using breadcrumbs only.

### Open a terminal and navigate

- Outcome: Use a terminal to identify and change the current folder with absolute and relative paths.
- Prerequisites:
  - files-folders
- Terms:
  - terminal
  - shell
  - cli
  - argument
- Key actions:
  - Open the terminal
  - Print the location
  - List the folder
  - Navigate relatively
  - Use quotes and Tab
- Command goals:
  - Show the current folder
  - List visible contents
  - Move to the parent folder
- Visual: path — Relative movement
- Practice: From learn-git, enter practice/notes using a relative path, return two levels, then enter it using its absolute path.

### Create, read, copy, move, and remove files

- Outcome: Manage practice text files in each supported shell and explain output redirection.
- Prerequisites:
  - terminal-navigation
- Terms:
  - extension
- Key actions:
  - Confirm location
  - Create and write
  - Read and append
  - Copy, move, rename
  - Remove only practice copies
- Command goals:
  - Create an empty text file
  - Write one line
  - Display the file
- Visual: flow — Safe file operation loop
- Practice: Create checklist.txt with one item, append a second item, read it, and keep the file for later Git lessons.
