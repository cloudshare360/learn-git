# 0. Start here

## Module overview

- Goal: Use the course safely and learn basic computer actions.
- Lesson count: 2
- Visual types: orientation, decision

## Lessons

### Welcome: zero knowledge assumed

- Outcome: Identify instructions, buttons, commands, output, and placeholders without risking your computer.
- Terms:
  - browser
  - terminal
  - shell
- Key actions:
  - Choose your system
  - Read command cards
  - Use the course tree
  - Practice common actions
- Visual: orientation — The learning screen
- Practice: Select your operating system, change the color theme, expand this module, and return to this lesson.

### Safety, saving, and secrets

- Outcome: Recognize reversible actions, destructive actions, and information that must remain private.
- Terms:
  - version_control
- Key actions:
  - Save deliberately
  - Treat deletion carefully
  - Keep secrets outside Git
- Visual: decision — Before a risky action
- Practice: Write down three things you will never paste into a public repository.
